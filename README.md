# Opportunistic AI Compute for Renewable Curtailment

Reproducibility materials for the study **"Opportunistic AI compute as a dispatchable sink for curtailed renewable electricity."** The project evaluates whether queued AI Spot jobs can be admitted, scheduled, and power-capped to follow renewable electricity that would otherwise be curtailed.

The final study combines:

- 20 independent six-hour CAISO curtailment windows from 2025;
- a fixed portfolio of 18 empirical Alibaba A100 Spot jobs;
- field-measured A100 power-performance calibration at 250, 300, 350, and 400 W caps; and
- a 945-variable QUBO solved with D-Wave Leap Hybrid and benchmarked against CPLEX and simulated annealing.

The final D-Wave schedules achieve a mean tracking RMSE of 0.511 kW, a mean scheduled-to-target energy ratio of 0.9994, and approximately 210 baseline-equivalent GPU-hours of useful work per event.

## Quick start: regenerate the publication figures

This is the recommended offline workflow. It uses only archived inputs and completed results; it does not submit optimization jobs.

```bash
python -m pip install -r requirements.txt
jupyter notebook 05_publication_analysis_and_plots.ipynb
```

Run all cells in notebook 05. It reads the frozen files in `data/` and writes PDFs to `figures/`.

## Full workflow

Run the notebooks in this order when reconstructing the experiments:

1. `01_prepare_real_caiso_alibaba_data.ipynb`
2. `01B_prepare_field_calibrated_data.ipynb`
3. `02B_CPLEX_SA_field_calibrated_testing.ipynb`
4. `03_DWave_LeapHybridBQM_final_20_events.ipynb`
5. `04_DWave_postrun_analysis.ipynb`
6. `publication_figures.ipynb`

The raw CAISO workbook (`production-and-curtailments-data-2025.xlsx`) and Alibaba archive (`clusterdata-master.zip`) are included locally. The Emerald field-artifact archive is retained as `emerald-ai-demo-may-2025-main.zip`.

## Requirements and credentials

Install the Python dependencies with `python -m pip install -r requirements.txt`. Classical experiments additionally require a working IBM ILOG CPLEX/DOcplex installation. The D-Wave campaign notebook requires an authenticated D-Wave Leap account configured for the Ocean SDK; do not run it unless you intend to use remote solver quota.

## Scope and reproducibility notes

- The study is an offline scheduling analysis: each six-hour curtailment trajectory is assumed known ahead of time.
- System-wide CAISO curtailment supplies temporal shape and relative severity. A common scaling factor maps it to the 256-A100 reference-cluster flexibility envelope.
- Power-performance transfer is conservative: it uses the minimum measured normalized throughput across eight field workloads at each selected cap.
